== 1. Overview
This document outlines the data models and service interfaces for a futures trading application based on a microservice architecture. The application integrates the Tradovate API for live market data and execution, and the Google Gemma 5 model for market analysis. All microservices run on embedded Tomcat servers.

The system consists of the following core services:

* **API Gateway**: A Spring Cloud Gateway acting as the central entry point, handling routing, rate limiting, and security.
* **Account Service**: Manages user profiles and Tradovate credentials.
* **Trading Service**: Handles contract selection, order placement, and live market data.
* **Analysis Service**: Integrates Gemma 5 to analyze chart data and volume metrics.
* **Bot Service**: Executes trades autonomously based on basic strategies and Gemma 5 analysis.

=== 3.2. Trading Service API
_Interfaces directly with the Tradovate API for fetching contracts, market data streams, and execution._

[source,java]
----
public interface TradingService {
    // Contract Management
    Contract getContractDetails(String symbol);
    List<Contract> searchContracts(String keyword);

    // Order Management
    OrderDetails placeOrder(OrderRequest orderRequest);
    OrderDetails modifyOrder(String orderId, int newQuantity, Double newPrice);
    OrderDetails cancelOrder(String orderId);
    
    List<OrderDetails> getActiveOrders(String accountId);
    List<OrderDetails> getOrderHistory(String accountId, LocalDateTime startTime, LocalDateTime endTime);
    
    // Position Management
    List<Position> getOpenPositions(String accountId);
    void closeAllPositions(String accountId);
}

public interface MarketDataService {
    // Streaming connections via Websocket/Tradovate
    void subscribeToLiveQuotes(String symbol, LiveQuoteListener listener);
    void unsubscribeFromLiveQuotes(String symbol);
    
    void subscribeToChartData(String symbol, String timeframe, ChartDataListener listener);
}

public interface LiveQuoteListener {
    void onMarketDataReceived(MarketDataPoint dataPoint);
}

public interface ChartDataListener {
    void onChartDataUpdate(ChartData chartData, VolumeMetrics volumeMetrics);
}
